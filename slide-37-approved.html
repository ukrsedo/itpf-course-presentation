Qualitative sourcing comparison

Private

Dedicated to one organisation and tailored to its operating and control requirements.
Relative costHigh: dedicated capacity and operating capability.
ControlVery high: architecture, access and governance can be customised.
ScalabilityModerate: constrained by owned or reserved capacity.
Security / complianceStrongest custom control, but the organisation carries more responsibility.
Integration complexityMedium to high, especially with legacy environments.

Community

Shared by organisations with common mission, policy, security or regulatory requirements.
Relative costMedium to high, with infrastructure and governance costs shared.
ControlHigh, but decisions require shared governance.
ScalabilityModerate: larger than a single private cloud but limited to the community.
Security / complianceDesigned around common sector or regulatory controls.
Integration complexityHigh where multiple organisations and standards must align.

Hybrid

Connects private or on-premises environments with public cloud services.
Relative costMedium to high because several environments must be operated.
ControlHigh for sensitive workloads; lower in public components.
ScalabilityHigh when public cloud is used for variable demand.
Security / complianceSupports workload segregation, but controls must remain consistent.
Integration complexityHighest: identity, data, networking and governance must work across environments.

Public

Provider-owned, multi-tenant infrastructure offered to customers as standardised services.
Relative costLow entry cost, but total spend varies with usage and configuration.
ControlLower: customers operate within the provider's service model.
ScalabilityVery high: resources can be provisioned rapidly.
Security / complianceStrong standard controls under a shared-responsibility model.
Integration complexityLow to medium for cloud-native use; higher when connected to legacy systems.
No model is universally cheaper or safer. The result depends on workload design, utilisation, data sensitivity, internal capability and contractual terms.
