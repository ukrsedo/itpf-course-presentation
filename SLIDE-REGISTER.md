## Maintenance

- Edit the file listed in the Source file column.
- When a slide moves, renumber and rename the affected source files, update their HTML titles and accessibility labels, and update `index.html` and this register in the same commit.
- `index.html` contains the presentation order. `slide-index.html` is the browser-friendly index.
- `assistantDeckNumber` and `assistantLegacyNumber` are compatibility identifiers for deployed Course Assistant versions. They are not current slide positions. Retain them with their content when slides move.
- Image asset filenames may retain their original source numbers. The HTML file and this register identify the current slide.
