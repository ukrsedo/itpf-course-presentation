How can procurement control token waste?

Token waste is unnecessary AI consumption caused by avoidable prompts, excessive context, repeated calls, unsuitable models, or poorly designed workflows.

Discussion task

  • Identify where unnecessary token consumption can occur.
  • Select the most effective procurement or governance controls.
  • Explain who should own each control: procurement, IT, finance, or the user.

Demand controls

Set quotas, approval thresholds, budgets, alerts, and chargeback or showback by team.

Technical controls

Match the model to task complexity, shorten prompts, trim context, cache repeated outputs, and remove unnecessary calls.

Your discussion notes

Record two or three controls and explain which function should own them. This is not a scored activity.
