Session 3 Cloud Computing

SaaS License Metrics

👤

User

  • The number of users/clients/instances, where “client” means device and “instance” means an installation or use of the software
  • User role (guest, general user, power user, admin)
  • Named User
  • Client Access License (CAL)
⚙

Consumption

  • Pay-as-you-go (per use, per transaction or else)
  • Hard / soft capped (e.g., up to X transactions during a license period and then a hard stop or paying an overage rate)
  • Company metrics
  • Employees / transactions / locations
  • Revenue (self-declared or from an annual report)
⇄

Concurrent

  • Concurrent Users/Instances.
  • Floating users, i.e., X floating licenses for Y users, where X < Y
☁

Cloud

  • Cloud credits
💻

Capacity / Hardware

  • Type of machine (desktop, thin client, physical or virtual server)
  • Size of a machine (cores, processors, sockets)
  • Host ID
  • Token
◫

Feature

  • Feature-based
  • Floating feature
AI

AI Features

  • Flat fee
  • Annual commitment
  • Input/output tokens
  • API calls
↻

Unlimited

  • Unlimited everything (ULA – Unlimited License Agreement)
  • Unlimited users / capacity / consumption, where unlimited users capped on transactions, and so on
