Support
1

Customer Support

  • Act as Single Point of Contact for all tickets
  • Assist end users on daily operations
  • Address Application usage requests
  • Provide End User training
  • Scheduled Job Management
  • Provide issue analysis to L2 if unable to resolve
  • Provide ticket updates to end users
  • Coordinate with L2 on open issues
2

Business Process Support

  • Ensure application availability to end users
  • Ensure business continuity
  • Resolve usage queries
  • Configuration Support
  • Admin – User management
  • Manage workflows, roles, minor label changes etc.
  • manage minor enhancements
  • Resolve Integration failures
  • Patch updates for data correction
  • Testing of any developments
  • Provide Training to L1
  • Coordinate with L3 & L4 team
3

Technical Support

  • Change Requests related to new functionality development or integration developments where the effort is upto 3 man-days
  • Bug Fixes
  • Deep Configurations
  • Temporary Fixes
  • Enhancement Tag Deliveries
4

Product Support

(Part of Subscription)
  • Standard Product Support
  • Patch updates
  • Version Upgrades
  • Change Request where code level changes are required
